What we attack

Six attack surfaces covering how AI products actually get broken.

Prompt injection & jailbreaks

One-shot and multi-turn; direct and indirect injection via retrieved content and tools.

System prompt & data leakage

Coaxing the model to reveal instructions, PII, credentials, financials, and proprietary data.

Agent abuse

Tool misuse, memory and context poisoning, goal hijack, privilege escalation, unsafe code execution.

RAG & knowledge poisoning

Malicious documents in the index, retrieval-time injection, source-attribution integrity, poisoned grounding.

Evasion & prompt brittleness

Repeat trials, perturbation, stochastic-output variability; prompts that fail once and succeed later.

Resource & cost exhaustion

DoS, token thrash, quota drain, rate-limit bypass, and denial-of-wallet attacks.

How an engagement runs

Four steps from scope to verified fix.

Step 01 Bound

Scope

Return after remediation to verify fixes; lightweight follow-up engagement.
